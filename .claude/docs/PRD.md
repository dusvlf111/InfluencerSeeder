# 인플루언서 시딩기 — Product Requirements Document

## 1. 개요

**제품명:** 인플루언서 시딩기  
**버전:** 1.0  
**대상 플랫폼:** macOS, Windows (PyQt6 데스크탑 앱)  
**배포 방식:** `.app` (macOS), `.exe` (Windows) — PyInstaller 빌드

인스타그램에서 특정 해시태그 또는 캡션 키워드로 인플루언서 후보를 자동 수집하고, 구글 시트에 저장/관리하는 내부 도구.

---

## 2. 사용자 스토리

| # | 역할 | 원하는 것 | 이유 |
|---|------|-----------|------|
| 1 | 마케터 | 해시태그로 인플루언서 목록 수집 | 수동 검색 시간 절약 |
| 2 | 마케터 | 팔로워 범위 필터링 | 마이크로/매크로 인플루언서 구분 |
| 3 | 마케터 | 이미 협업한 계정 제외 | 중복 접근 방지 |
| 4 | 마케터 | 구글 시트에 결과 자동 저장 | 팀 공유 및 중복 관리 |
| 5 | 마케터 | 앱처럼 실행 (브라우저 불필요) | 비개발자도 쉽게 사용 |

## 3. 기능 요구사항

### 3.1 인플루언서 수집

#### 해시태그 검색 모드
- 특정 해시태그(#)로 인스타그램 게시물 탐색
- 게시물 작성자의 계정명, 팔로워 수, 프로필 URL, 게시물 URL 수집
- 최근(Recent) 탭 기준으로 수집

#### 캡션 키워드 검색 모드
- 캡션에 특정 키워드가 포함된 게시물 탐색
- 관련 해시태그 자동 탐색 후 최대 5개 순회
- 일반 검색 결과 → 관련 해시태그 순으로 수집

#### 공통
- 수집 목표 수: 5~200명 설정 가능
- 동일 계정 중복 수집 안 함
- 연속 10개 실패 시 자동 종료 (조기 종료 방지)

### 3.2 팔로워 필터

| 항목 | 선택지 |
|------|--------|
| 최소 팔로워 | 제한없음, 1천, 5천, 1만, 3만 |
| 최대 팔로워 | 제한없음, 5천, 1만, 3만, 5만, 10만 |

- 필터 설정 시 각 계정 수집 즉시 팔로워 수 확인 후 필터링
- 필터 없을 시 수집 완료 후 일괄 팔로워 수 수집

### 3.3 제외 계정 관리

- 제외할 계정 수동 등록 (쉼표 또는 공백 구분 입력)
- 등록된 계정은 수집 결과에서 제외
- `data/excluded.json`에 영구 저장 (앱 재시작 후에도 유지)
- 구글 시트 "제외계정" 시트와 양방향 동기화

### 3.4 구글 시트 연동

#### 시트 구조 (3개 시트)

**수집결과**
| account | profile_url | followers | caption_snippet | post_url |
|---------|-------------|-----------|-----------------|----------|
| @alice | https://... | 1.2만 | 취준 열심히... | https://... |

- 기존 항목 기준 `account` 컬럼으로 중복 제거 후 append

**제외계정**
| account |
|---------|
| @letscxreer |

- 덮어쓰기 방식으로 동기화

**설정** (예비)
| key | value |
|-----|-------|
| min_followers | 0 |
| max_followers | 10000 |

#### 인증
- Google 서비스 계정 JSON 키 파일 사용
- 설정 화면에서 파일 경로 지정
- 연결 테스트 기능 제공

### 3.5 설정 화면

- **구글 시트 탭**: Spreadsheet ID, 서비스 계정 JSON 파일 선택, 연결 테스트, 제외계정 불러오기
- **의존성 설치 탭**: `pip install -r requirements.txt` 실행 및 출력 확인

### 3.6 로그인 플로우

1. 수집 시작 시 Chrome 브라우저 자동 실행
2. 사용자가 브라우저에서 인스타그램 수동 로그인
3. 앱에서 "로그인 완료" 버튼 클릭 → 수집 재개
4. 로그인 정보 앱에 저장하지 않음 (보안)

## 4. 비기능 요구사항

### 4.1 배포
- macOS: `.app` 번들 (더블클릭 실행, `시작하기.command` 제공)
- Windows: 단일 `.exe` 파일
- PyInstaller로 빌드, 의존성 번들 포함

### 4.2 데이터 저장
- 서버 없음 — 모든 데이터는 로컬 파일 또는 구글 시트
- `data/excluded.json`: 제외 계정 목록
- `data/settings.json`: 앱 설정 (팔로워 기본값, 구글 시트 정보)

### 4.3 UI/UX
- 다크 테마 고정 (디자인 토큰 `design/tokens.py` 기준)
- 실시간 진행 상황 표시 (로그 + 프로그레스바)
- 브라우저 없이 독립 실행

## 5. 기술 스택

| 항목 | 기술 |
|------|------|
| UI 프레임워크 | PyQt6 |
| 스크래핑 | Selenium + ChromeDriver (webdriver-manager 자동 관리) |
| 구글 시트 | gspread + google-auth |
| 로컬 저장 | JSON 파일 (`data/`) |
| 패키징 | PyInstaller |
| 테스트 | pytest |

## 6. 아키텍처

```
main.py                  진입점 (QApplication)
├── ui/
│   ├── main_window.py   QMainWindow (패널 조합)
│   ├── panels/
│   │   ├── control_panel.py   좌측 컨트롤 (검색, 필터, 버튼)
│   │   └── results_panel.py   우측 결과 (테이블, 로그, 진행)
│   ├── dialogs/
│   │   └── settings_dialog.py 설정 다이얼로그
│   └── widgets/
│       ├── follower_filter.py  팔로워 범위 위젯
│       └── excluded_widget.py  제외 계정 위젯
├── core/
│   ├── scraper.py       ScraperThread(QThread)
│   ├── storage.py       JSON 파일 CRUD
│   └── sheets.py        구글 시트 API 래퍼
├── design/
│   ├── tokens.py        색상·타이포·간격 상수
│   └── stylesheet.py    QSS 생성기
└── data/                런타임 데이터 (gitignored)
```
