# PRD: InfluencerSeeder v2 — CSV-based, Step-flow Scraper

## Overview
Instagram influencer data collection desktop app (PyQt6).
All storage (settings, selectors, excluded, results) moves to CSV files.
Scraping follows an exact 6-step UI flow matching Instagram's current UI.

---

## Scraping Flow (6 Steps)

Based on screenshots in .claude/tasks/:

```
[START] Instagram opens in Chrome
  ↓
[MODAL] "Log in to Instagram, then click Confirm"
  ↓ user clicks Confirm
For tag_index = 0, 1, 2, ... max_tags-1:
  Step 1: Click search icon (돋보기) in left sidebar
          [random delay: step1_delay_min ~ step1_delay_max]
  Step 2: Type #keyword in search input
          [random delay: step2_delay_min ~ step2_delay_max]
  Step 3: Click tag_index-th tag suggestion in results list
          [random delay: step3_delay_min ~ step3_delay_max]
  ↓ Tag grid page loads (e.g. /explore/tags/인턴/)
  Collect post URLs from grid (scroll until posts_per_tag posts found)
  For post_index = 0 .. posts_per_tag-1:
    Step 4: Navigate to post URL
            [random delay: step4_delay_min ~ step4_delay_max]
    Step 5: Click profile link in post header
            [random delay: step5_delay_min ~ step5_delay_max]
    Step 6: Extract & save profile data to results.csv
            [random delay: step6_delay_min ~ step6_delay_max]
    Navigate back to tag grid URL
[END] done_signal emitted
```

**Key behavior:**
- After collecting posts_per_tag posts from tag 0, re-run Steps 1-3 to navigate to tag 1 suggestion, etc.
- Skips accounts already in excluded.csv or results.csv (dedup by username).
- Applies min/max follower filters during Step 6.
- Progress shown per step in UI.

## UI Architecture

### Main Window (QStackedWidget)
- Page 0: Main view (ControlPanel + ResultsPanel in QSplitter)
- Page 1: Settings page (SettingsView)

### ControlPanel (left ~320px)
- Mode: Hashtag / Caption keyword (QButtonGroup)
- Search term: QLineEdit
- Count: QSpinBox
- Min/Max followers: QComboBox
- [Start Collection] [Stop] buttons
- Step progress indicator (current step label + step dots)
- [Settings] button at bottom

### ResultsPanel (right)
- QProgressBar
- QTabWidget:
  - Tab 1 "Results": QTableWidget (No. | Username | Followers | Bio | Post URL)
  - Tab 2 "Log": QTextEdit (color-coded: step, info, warning, error)
- [Import CSV] [Export CSV] buttons
  - Export = QFileDialog.getSaveFileName → shutil.copy(results.csv, dest)
  - Import = QFileDialog.getOpenFileName → load CSV rows into table

### SettingsView (full page, QStackedWidget page 1)
- Header: [<< Back] [Save All]
- QTabWidget with 3 tabs:
  - Tab 1 "Collection": min/max followers, posts_per_tag, max_tags
  - Tab 2 "Delays": table of step delays (step name | min sec | max sec) — editable
  - Tab 3 "Selectors": table (step_id | step_name | type | selector_value) — editable
  - Tab 4 "Excluded": QTableWidget with username column + Add/Remove buttons
- Save writes all tables back to respective CSV files
