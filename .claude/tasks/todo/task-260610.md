## 프로젝트 컨벤션 핵심 요약

- **스토리지 격리:** 모든 파일 I/O 는 `core/storage.py`(또는 신규 `core/run_logger.py`)에만. 경로는 `DATA_DIR` 기준, CSV 는 `utf-8-sig`+`csv.DictReader/Writer`, 파일 없으면 기본값 기록 후 반환, 손상 시 기본값. `DATA_DIR` 정의를 바꾸지 말 것(테스트가 monkeypatch).
- **신호/슬롯:** `ScraperThread`(QThread)는 UI 직접 조작 금지, `pyqtSignal` emit 만. 기존 신호 시그니처 변경 금지, 신규는 추가만(`skip_signal`, `blocked_signal`, `imported`, `selector_test_requested`).
- **디자인 토큰:** 색상/여백은 `design/tokens.py`(`Colors.*`/`Spacing.*`/`Radius.*`)만. QSS 에 hex 직접 금지. 스타일은 `objectName` + 전역 스타일시트.
- **테스트 격리(pytest):** storage 는 `monkeypatch.setattr(storage,"DATA_DIR",tmp_path)`; selenium 은 `MagicMock()`; `time.sleep`/`random.uniform` 은 patch; UI 는 `QApplication` session fixture(pytest-qt 미설치) + 순수 로직 위주. 실제 네트워크/브라우저 호출 금지.
- **마이그레이션:** v2 `settings.csv` → web/delays/flow/target 분리하되 기존 `load_settings` 등은 호환 위해 유지(추가 위주).
