# 인플루언서 시딩기

인스타그램 해시태그 / 캡션 키워드 기반 인플루언서 프로필 자동 수집 도구.
내장 브라우저에서 실제 클릭 방식으로 동작해 봇 탐지를 최소화합니다.

## 설치 및 실행

### Windows

```bat
run_windows.bat
```

첫 실행 시 가상환경(`.venv`) 및 의존성이 자동 설치됩니다.

### macOS

```bash
./run_mac.command
```

### 직접 실행

```bash
cd src
.venv/bin/python main.py
```

### 1. 메인 화면

<!-- 📸 스크린샷 삽입 위치 — 메인 화면 전체 캡처본을 아래에 붙여넣으세요 -->

좌측 컨트롤 패널과 우측 결과 패널, 중앙 내장 브라우저로 구성됩니다.

| 영역 | 설명 |
|------|------|
| 좌측 컨트롤 패널 | 검색 모드·검색어·수집 수·팔로워 필터 설정 및 수집 시작/정지 버튼 |
| 중앙 브라우저 | 인스타그램이 열리는 내장 브라우저. 수집 중 실제 클릭 동작이 여기에서 일어납니다 |
| 우측 결과 패널 | 진행률, 수집 결과 테이블, 로그 확인 |

**컨트롤 패널 항목**

| 항목 | 설명 |
|------|------|
| 검색 모드 | `# 해시태그` — 해시태그로 게시물 탐색 / `캡션 키워드` — 계정 검색 결과에서 수집 |
| 검색어 | 쉼표 또는 줄바꿈으로 여러 키워드 입력 가능 (`취준생, 인턴`) |
| 수집 수 | 수집할 계정 목표 수 (5~200) |
| 팔로워 범위 | 수집 대상 팔로워 최소/최대 필터 |
| 제외 계정 | 수집에서 제외할 계정 목록 (설정 탭과 공유) |

### 2. 설정 — 딜레이 탭

<!-- 📸 스크린샷 삽입 위치 — 설정 화면에서 "딜레이" 탭을 열고 캡처한 이미지를 아래에 붙여넣으세요 -->
<!-- ![설정 딜레이 탭](README/settings_delays.png) -->

각 수집 단계 사이에 적용되는 랜덤 대기 시간을 설정합니다.
딜레이가 길수록 봇 탐지 위험이 줄어듭니다.

| 항목 | 설명 |
|------|------|
| Step 1 ~ Step 6 | 수집 단계(검색 아이콘 클릭 → 검색어 입력 → 태그 선택 → 게시물 열기 → 프로필 진입 → 저장) 각각의 대기 |
| Return to Tag Grid | 프로필 → 게시물 그리드로 돌아올 때 대기 |
| Scroll (per scroll) | 그리드 스크롤 시 대기 |
| Typing (per character) | 검색어 입력 시 글자당 대기 |
| Profile Screenshot | 프로필 화면 캡처 직전 대기 (페이지가 완전히 로딩될 때까지) |

Min / Max 셀을 더블클릭하면 직접 입력할 수 있습니다. 단위는 초(sec).

### 4. 설정 — 제외 계정 탭

<!-- 📸 스크린샷 삽입 위치 — 설정 화면에서 "제외 계정" 탭을 열고 캡처한 이미지를 아래에 붙여넣으세요 -->
<!-- ![설정 제외 계정 탭](README/settings_excluded.png) -->

수집에서 제외할 계정(@username)을 관리합니다.
이미 수집된 계정은 자동으로 중복 제외 처리되며, 여기에 추가하면 수집 대상에서 완전히 배제됩니다.

- **추가**: 입력란에 `@username` 또는 `username` 입력 후 Enter
- **삭제**: 항목 선택 후 삭제 버튼

### 5. 설정 — 버튼매핑 탭

<!-- 📸 스크린샷 삽입 위치 — 설정 화면에서 "버튼매핑" 탭을 열고 캡처한 이미지를 아래에 붙여넣으세요 -->
<!-- ![설정 버튼매핑 탭](README/settings_mapping.png) -->

수집 각 단계에서 클릭할 요소의 CSS 셀렉터 / XPath / 좌표를 설정합니다.
인스타그램 UI가 변경되어 수집이 멈출 때 여기서 셀렉터를 업데이트합니다.

**셀렉터 추가 방법**
1. 브라우저에서 해당 요소 우클릭 → 검사
2. 요소 우클릭 → Copy → `Copy XPath` 또는 `Copy selector`
3. 해당 스텝 그룹에서 **후보 추가** → Type 선택 → Selector Value에 붙여넣기

| Type | 설명 |
|------|------|
| xpath | XPath 표현식 |
| css | CSS 셀렉터 |
| coord | `x,y` 좌표 클릭 (셀렉터 실패 시 폴백) |

스텝마다 후보를 여러 개 등록하면 위에서부터 순서대로 시도하고, 실패 시 다음 후보로 넘어갑니다.

### 6. 결과 — Results 탭

<!-- 📸 스크린샷 삽입 위치 — 수집 후 Results 탭이 활성화된 상태를 캡처한 이미지를 아래에 붙여넣으세요 -->
<!-- ![결과 테이블](README/results_table.png) -->

수집된 계정 목록을 테이블로 보여줍니다.

| 컬럼 | 설명 |
|------|------|
| # | 수집 순번 |
| 유저네임 | `@username` — 더블클릭 시 프로필 페이지 열기 |
| 팔로워 / 팔로잉 / 게시물 | 수집 시점 수치 (천단위 콤마 표시) |
| 소개 | Bio 첫 120자. 전체 내용은 마우스 툴팁으로 확인 |
| 링크 | 웹사이트 > 게시물 > 프로필 순 — 더블클릭 시 열기 |

**행에 마우스를 올리면** 400ms 후 [프로필 상세 모달](#8-프로필-상세-모달)이 자동으로 열립니다.

**버튼**

| 버튼 | 설명 |
|------|------|
| Import CSV | 외부 CSV 파일을 불러와 테이블에 추가 |
| Export CSV | 현재 결과를 CSV 파일로 저장 |

### 7. 결과 — Log 탭

<!-- 📸 스크린샷 삽입 위치 — 수집 중 Log 탭 화면을 캡처한 이미지를 아래에 붙여넣으세요 -->
<!-- ![로그 탭](README/results_log.png) -->

수집 진행 중 발생하는 모든 이벤트를 색상 코드로 실시간 출력합니다.

| 색상 | 의미 |
|------|------|
| 초록 (`[OK]`) | 계정 수집 성공 |
| 빨강 (`[ERROR]` / `[blocked]`) | 오류 또는 차단 감지 |
| 주황 (`[wait]` / `[skip]`) | 대기 중 또는 중복·필터 건너뜀 |
| 보라 (`[step]`) | 현재 진행 단계 |
| 회색 | 상세 동작 로그 |

로그인이 필요한 경우 이 탭에 **"로그인 완료"** 버튼이 나타납니다.
브라우저에서 인스타그램 로그인 후 버튼을 눌러 수집을 재개합니다.

### 8. 프로필 상세 모달

<!-- 📸 스크린샷 삽입 위치 — Results 탭에서 행에 호버해 모달이 열린 상태를 캡처한 이미지를 아래에 붙여넣으세요 -->
<!-- ![프로필 상세 모달](README/profile_detail.png) -->

Results 테이블에서 행에 마우스를 올리면 나타나는 상세 정보 창입니다.

- 수집 당시 프로필 페이지 **캡처 이미지** (전체 화면)
- 유저네임, 팔로워/팔로잉/게시물 수
- 소개글, 웹사이트, 프로필 URL
- 출처 태그, 수집 일시

텍스트는 마우스로 드래그해 복사할 수 있습니다.

## 수집 흐름

```
[시작] 검색 아이콘 클릭
  └─ 검색창 클릭(활성화)
     └─ 검색어 입력 (#키워드 또는 키워드)
        └─ [해시태그 모드] 태그 제안 클릭 → 게시물 그리드
           └─ 게시물 이미지 클릭 (posts_per_tag 개)
              └─ 프로필 이름 클릭
                 └─ 프로필 페이지 로딩 대기
                    └─ 데이터 추출(팔로워/소개글/웹사이트 등)
                       └─ screenshot 대기 → 화면 캡처 저장
                          └─ results.csv 저장 → 뒤로가기 반복
        └─ [캡션 키워드 모드] 검색 결과 계정 클릭 → 프로필 직접 진입
```

중복 계정, 팔로워 범위 외, 제외 목록 계정은 자동으로 건너뜁니다.

## 데이터 저장 위치

모든 데이터는 `src/data/` 에 CSV 파일로 저장됩니다.

| 파일 | 내용 |
|------|------|
| `data/results.csv` | 수집된 계정 전체 (username, followers, bio, website 등) |
| `data/screenshots/` | 프로필 페이지 캡처 이미지 (`{username}.png`) |
| `data/selectors.csv` | 버튼매핑 셀렉터 설정 |
| `data/delays.csv` | 딜레이 설정 |
| `data/flow.csv` | 수집 흐름 설정 |
| `data/excluded.csv` | 제외 계정 목록 |
