# 인플루언서 시딩기

인스타그램 해시태그 / 캡션 키워드 기반 인플루언서 프로필 자동 수집 도구.  
내장 브라우저에서 실제 클릭 방식으로 동작해 봇 탐지를 최소화합니다.

---

## 다운로드

[**GitHub Releases**](https://github.com/dusvlf111/InfluencerSeeder/releases/latest) 에서 최신 버전을 받으세요.

| 파일 | 대상 |
|------|------|
| `InfluencerSeeder-vX.X.X-mac.zip` | macOS (Apple Silicon M1/M2/M3/M4) |
| `InfluencerSeeder-vX.X.X-windows.zip` | Windows 10/11 |

---

## 설치 및 실행

### macOS

1. ZIP 파일 압축 해제
2. `실행방법.html` 을 열어 안내에 따라 **최초 1회** 보안 허용 설정
3. 이후 `인플루언서시딩기.app` 더블클릭으로 바로 실행

> ⚠️ macOS 보안 정책으로 첫 실행 시 추가 절차가 필요합니다. ZIP 내 `실행방법.html` 을 참고하세요.

### Windows

1. ZIP 파일 압축 해제
2. `인플루언서시딩기` 폴더 안의 `인플루언서시딩기.exe` 실행
3. 사용법은 `사용방법.html` 참고

---

## 사용법

### 기본 흐름

1. 앱 실행 → 인스타그램 **한국어로 변경** 후 로그인
2. 좌측에서 **검색 모드** 선택 (해시태그 / 캡션 키워드)
3. **검색어** 입력, **수집 수** 및 **팔로워 범위** 설정
4. **수집 시작** 클릭
5. 완료 후 **Export CSV** 로 데이터 저장

자세한 사용법은 ZIP 내 **`사용법.html`** 을 참고하세요.

## 화면 구성

### 메인 화면

앱을 시작하면 나타나는 기본 화면입니다.  
좌측 컨트롤 패널 · 중앙 내장 브라우저 · 우측 결과 패널로 구성됩니다.

| 영역 | 설명 |
|------|------|
| 좌측 컨트롤 패널 | 검색 모드·검색어·수집 수·팔로워 필터 설정 및 수집 시작/정지 버튼 |
| 중앙 브라우저 | 인스타그램이 열리는 내장 브라우저. 수집 중 실제 클릭 동작이 여기에서 일어납니다 |
| 우측 결과 패널 | 진행률, 수집 결과 테이블, 로그 확인 |

**컨트롤 패널 항목**

| 항목 | 설명 |
|------|------|
| 검색 모드 | `# 해시태그` — 해시태그로 게시물 탐색 / `캡션 키워드` — 계정 검색 결과에서 수집 |
| 검색어 | 쉼표 또는 줄바꿈으로 여러 키워드 입력 가능 (`취준생, 인턴`) |
| 수집 수 | 수집할 계정 목표 수 |
| 팔로워 범위 | 수집 대상 팔로워 최소/최대 필터 |
| 제외 계정 | 수집에서 제외할 계정 목록 (설정 탭과 공유) |

---

### 설정 탭

좌측 하단 **설정** 버튼으로 진입합니다.

| 탭 | 설명 |
|----|------|
| 타겟 | 팔로워/팔로잉/게시물 수 필터 세부 설정 |
| 딜레이 | 각 수집 단계 사이 대기 시간(초) 설정. 길수록 탐지 위험 감소 |
| 수집 설정 | 키워드당 게시물 수, 첫 게시물 건너뛰기 여부 |
| 제외 계정 | 수집 제외 계정 관리 |
| 버튼매핑 | 인스타그램 UI 요소 CSS/XPath 셀렉터 관리 (UI 변경 시 수동 업데이트) |

---

### 결과 패널

| 탭 | 설명 |
|----|------|
| Results | 수집된 계정 테이블. 행 호버 시 프로필 상세 모달 표시 |
| Log | 수집 중 실시간 이벤트 로그 |

**Import / Export CSV** 버튼으로 데이터를 불러오거나 내보낼 수 있습니다.

## 수집 흐름

```
[시작] 검색 아이콘 클릭
  └─ 검색창 클릭 → 검색어 입력
     └─ [해시태그] 태그 제안 클릭 → 게시물 그리드
        └─ 게시물 클릭 → 프로필 진입 → 데이터 추출 → CSV 저장
     └─ [캡션 키워드] 검색 결과 계정 → 프로필 직접 진입 → 데이터 추출
```

중복 계정, 팔로워 범위 외, 제외 목록 계정은 자동으로 건너뜁니다.

## 데이터 저장 위치

모든 데이터는 `src/data/` 에 CSV 파일로 저장됩니다.

| 파일 | 내용 |
|------|------|
| `data/results.csv` | 수집된 계정 전체 (username, followers, bio, website 등) |
| `data/screenshots/` | 프로필 페이지 캡처 이미지 |
| `data/selectors.csv` | 버튼매핑 셀렉터 설정 |
| `data/delays.csv` | 딜레이 설정 |
| `data/excluded.csv` | 제외 계정 목록 |
